GVC-Codes: Geschäftsvorfallcodes und ISO-Bank-Transaction-Codes

Der Geschäftsvorfallcode (GVC) ist die dreistellige Zahl, mit der deutsche Banken die Art einer Buchung kennzeichnen, zum Beispiel 166 für eine SEPA-Überweisungsgutschrift oder 109 für eine zurückbelastete SEPA-Lastschrift. Im camt.053-Kontoauszug steht neben dem GVC der internationale ISO 20022 Bank Transaction Code. Die Tabelle zeigt, welcher GVC welchem ISO-Code entspricht.

Die Zuordnung ist von der Deutschen Kreditwirtschaft festgelegt (Anhang 1 der Anlage 3 des DFÜ-Abkommens). Der GVC stammt ursprünglich aus dem MT940-Kontoauszug und wird im camt.053 weiterhin verwendet.

Wo steht der GVC im camt.053?

Der Bank Transaction Code steht im Element <BkTxCd>. Nach der Spezifikation der Deutschen Kreditwirtschaft ist dort immer der ISO-Code anzugeben, unter <Domn>: Domain, Family und SubFamily, zum Beispiel PMNT / RCDT / ESCT für eine SEPA-Überweisungsgutschrift. Zusätzlich kann die Bank unter <Prtry><Cd> einen zusammengesetzten Code angeben, dessen Teile mit „+“ verbunden sind:

  1. der vierstellige SWIFT-Transaction-Code,
  2. der Geschäftsvorfallcode (GVC),
  3. optional die Primanota-Nummer,
  4. die Textschlüsselergänzung, falls vorhanden.

Beispiele aus der Spezifikation: NRTI+109+9002/405+901 für eine SEPA-Lastschriftrückgabe, NTRF+116 für eine SEPA-Überweisung. Fehlt die Primanota, stehen zwei Pluszeichen hintereinander: NRTI+109++901.

Rückgaben: GVC und Rückgabegrund

Bei den GVC 108, 109, 110, 111, 159, 160, 181, 183 und 184 nennt der vierte Teil des Codes den Rückgabegrund als dreistellige Textschlüsselergänzung, zum Beispiel 901 für eine fehlerhafte IBAN. Die Bedeutung dieser Nummern und ihren ISO-Code finden Sie in der Übersicht der Rückgabegründe auf dem Kontoauszug.

Ein GVC, mehrere ISO-Codes

Für manche GVC sieht die Tabelle mehrere ISO-Codes vor, etwa je nach Purpose Code der Zahlung. Die Spalte „Hinweis“ nennt dann das Unterscheidungsmerkmal. Gibt es mehrere zulässige Varianten, entscheidet die Bank, welche sie verwendet.
