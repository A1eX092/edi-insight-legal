Code rejet SEPA / ISO 20022

AB06

HEURE LIMITE DEPASSEE

Erreur SCT Inst (negatives) CFONB 61
Signification

L'agent destinataire du message (système de compensation ou banque intermédiaire) n'a pas traité la transaction dans le délai maximal. La transaction est annulée.

Le délai maximum d'exécution (Time out) constaté par l'un des intervenants est dépassé. S'applique au Reject (SCT Inst).

Causes fréquentes
  • Ralentissement du système de compensation (CSM)
  • Incident chez une banque intermédiaire
  • Pic de charge sur la chaîne de traitement
Inclus dans les 3 résolutions offertes Débloquer gratuitement, sans mot de passe →
Résolution
  • Vérifier que le montant n'a pas été débité, ou qu'il a bien été recrédité
  • Réémettre le virement instantané un peu plus tard
  • Si le cas se répète, demander à votre banque si un incident est en cours sur le système de compensation
